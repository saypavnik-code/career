# Эскада

Личная профессиональная память сотрудника: быстрый захват идей и результатов,
превращение их в доказательства роста, понятный следующий карьерный шаг.

Продуктовое описание — см. `docs/ESCADA_PRODUCT_SPEC_V8.md` и
`docs/PRODUCT_CJM_AND_RECOMMENDATIONS.md`.

## Стек

- Next.js 15 (App Router), TypeScript, единый `app/globals.css`
- Статический экспорт (`output: 'export'`) для GitHub Pages
- Данные — в `localStorage` браузера, бэкенд для базовой работы не требуется
- Опциональная внешняя AI-подсказка через `NEXT_PUBLIC_ESCADA_AI_ENDPOINT`
  (не обязательна: без неё работает встроенный локальный guidance-движок,
  см. `app/career/local-guidance.mjs`)

## Разработка

Используйте Node.js 24.

```bash
npm ci
npm run dev          # локальный сервер разработки
npm run test:escada  # тесты доменной логики, PWA и контракта Performance Review
npm run build         # статическая сборка в out/
```

## Деплой

Деплой на GitHub Pages выполняется автоматически через
`.github/workflows/deploy-pages.yml` при пуше в `main`. Пайплайн:

1. чекаутит именно запушенный коммит;
2. `npm ci`, тесты, `next build`;
3. штампует `out/deploy-version.txt` = SHA задеплоенного коммита.

Проверить, что прод соответствует `main`:

```bash
curl -fsSL https://saypavnik-code.github.io/career/deploy-version.txt
git rev-parse origin/main
```

Значения должны совпадать.

## Принципы продукта

- Эскада — личная память сотрудника, не HR-система и не task-менеджер.
- Компетенции — ориентир, а не обязательный чеклист; никаких выдуманных процентов.
- AI/встроенная подсказка вызывается только явной кнопкой, никогда фоном.
- Ввод хранится в браузере. Запрос к настроенному AI отправляет контекст соответствующей функции только по действию пользователя.

## Performance Review

В одноимённой вкладке выберите оценку себя или коллеги, укажите период и вставьте пункты из своей формы, по одному на строку. Для Self Review подтвердите свой уровень. По умолчанию подставляется уровень из профиля. Шлюз использует 12 областей шкалы Digital Marketing для вопросов и итогового текста. Три уровня берутся из PDF с привязкой к страницам. Для младшего специалиста предусмотрен рабочий ориентир на основе требований к специалисту.

В итогах Self Review видно, какие компетенции подтверждаются ответами, где данных мало и какие области вне зоны работы. При возобновлении ранее начатого Self Review выберите уровень. Ответы и готовые черновики сохраняются. Peer Review оформляется в четыре фиксированных блока.

Пункты, отправленные ответы и черновики хранятся в этом браузере и видны в «Мои ревью». Они хранятся отдельно от экспорта профиля. Черновики можно копировать из редактора, отдельные ревью можно удалить из истории.

### Подключение локального агента

Шлюз запускается на компьютере, где открыт браузер. Он принимает запросы на `127.0.0.1:8787/review`, сверяет точный origin и передаёт инструкции и данные в OpenAI-совместимый `/v1/chat/completions`. Модель должна поддерживать JSON-ответы через `response_format: {"type":"json_object"}` и иметь контекст для всего интервью. По умолчанию шлюз разрешает локальные origin на порту 3000. Для GitHub Pages добавьте origin сайта без пути репозитория.

```bash
ESCADA_REVIEW_MODEL='your-model-id' \
ESCADA_REVIEW_COMPLETIONS_URL='http://127.0.0.1:11434/v1/chat/completions' \
ESCADA_REVIEW_ORIGINS='http://localhost:3000,https://saypavnik-code.github.io' \
npm run review:agent
```

Откройте профиль через имя внизу боковой панели. В «Подключении агента» сохраните адрес `http://127.0.0.1:8787/review` и начните интервью. При запросе браузера разрешите доступ к локальной сети для Escada. Чтобы выбрать другой порт, установите `ESCADA_REVIEW_PORT`. Если модель требует ключ, передайте `ESCADA_REVIEW_API_KEY` только в окружении шлюза. Приложение также принимает HTTPS-адрес собственного сервера с реализацией контракта из `app/performance-review/review-contract.mjs`. Self Review использует протокол v2, Peer Review — v1. После обновления перезапустите локальный шлюз. Существующее подключение AI-подсказок через `NEXT_PUBLIC_ESCADA_AI_ENDPOINT` используется отдельно.

## Интерфейс

В профиле можно выбрать плотность «Комфортно» или «Компактно». Плотность и адрес агента сохраняются в этом браузере.

На экране «Сегодня» черновик мысли сохраняется автоматически в этом браузере. Ctrl/⌘ + Enter сохраняет мысль в журнал. На доске «Идеи» статус можно поменять переносом или через список. В Wins отмена удаления доступна пять секунд и восстанавливает связи с идеей и отчётами.

Шрифты Golos Text и Source Serif 4 включены в сборку с лицензиями SIL OFL. Иконки навигации и элементов управления взяты из Lucide.

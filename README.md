# Развитие компетенций

Персональная Career OS для Senior Digital Marketer: фиксация активностей, компетенций и подтверждений, автоматическая генерация Weekly Review и других отчётов. Полностью статичное приложение — без бэкенда, без сборки, без npm.

## Технологии

- HTML5 / CSS3 / Vanilla JavaScript (ES-модули, ES2023)
- IndexedDB — основное хранилище данных
- LocalStorage — только настройки (тема, состояние UI)
- Zero build — работает сразу после загрузки на GitHub Pages

## Запуск локально

Модули (`type="module"`) не грузятся с `file://` в некоторых браузерах — поднимите любой локальный статический сервер из корня репозитория:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Деплой на GitHub Pages

1. Распакуйте архив в корень репозитория (или в `/docs`, если используете эту опцию).
2. Закоммитьте и запушьте.
3. В настройках репозитория: **Settings → Pages → Source** — выберите ветку и папку (`/root` или `/docs`).
4. Приложение будет доступно по адресу `https://<username>.github.io/<repo>/`.

Дополнительная конфигурация не требуется — нет build step, нет serverless-функций, нет переменных окружения.

## Структура проекта

```
index.html          — статичная оболочка (sidebar/topbar/content контейнеры)
manifest.json        — PWA-манифест (неактивен до появления service worker)
styles/               — дизайн-токены + компонентные стили
scripts/
  storage/            — IndexedDB-соединение, миграции, LocalStorage
  repositories/        — CRUD и запросы по каждой сущности
  domain/               — модели, бизнес-правила, справочники
  services/              — оркестрация use-case'ов (Application layer)
  reporting/              — генерация отчётов: шаблоны + экспортёры
  components/              — переиспользуемые UI-компоненты
  views/                     — экраны (Overview, Activities, Reports, Settings)
  utils/                      — чистые хелперы (даты, id, DOM, иконки)
tests/
  smoke.html                  — набор смоук-тестов поверх реальной IndexedDB
docs/
  architecture.md               — полная архитектурная документация
```

## Дизайн-система

Источник — приложенный `design.md`. Все токены (`styles/tokens.css`) перенесены 1:1, без добавления новых цветов/радиусов/отступов. Любое расширение дизайн-системы должно происходить через этот файл, а не точечными исключениями в компонентах.

## Тестирование

Поскольку сборки нет, юнит-тесты в привычном виде (Jest и т.п.) не подключены. Вместо этого `tests/smoke.html` — самостоятельная HTML-страница, которая:

- открывает временную (не боевую) IndexedDB-базу;
- прогоняет реальные операции через storage → repository → domain → service → reporting;
- проверяет ключевые инварианты (валидация, индексированные запросы, агрегация, генерация отчётов).

Откройте `tests/smoke.html` через тот же локальный сервер (`http://localhost:8000/tests/smoke.html`) после любых изменений в соответствующих слоях.

## Реализовано в этой версии

- Обзор (Overview): метрики недели, разбивка по компетенциям, последние активности
- Активности: форма фиксации + журнал текущей недели
- Отчёты: генерация Weekly Review в Markdown / HTML / JSON / PDF (печать)
- **Профессиональный рост**: выбор текущей должности (Специалист / Старший специалист / Ведущий специалист), сверка с полной шкалой компетенций отдела (12 направлений, 152 пункта — источник: `NEW_Шкала_уровней_компетенций_Digital.pdf`), подсветка пробелов текущего уровня и целей роста для следующего. Ручная отметка выполнения пункта + автоматическая подсказка о потенциальных активностях-доказательствах (сопоставление по однокоренным словам)
- **Победы**: лента зафиксированных достижений (без статусов планирования — как в Activities), создаются напрямую из пунктов шкалы компетенций на экране «Профессиональный рост» кнопкой «Зафиксировать победу». Учитываются в «Карте компетенций» как раздел доказательств для итоговой аттестации
- **Идеи**: независимый канбан-трекер (К выполнению / В работе / Готово) для организации мыслей и планов — без какой-либо связи со шкалой компетенций
- Настройки: текущая должность (с возможностью сбросить), экспорт/импорт JSON-бэкапа (включает прогресс по шкале и задачи), список тегов компетенций
- Обзор: карточка «Профессиональный рост» — общий % соответствия должности и три направления с наибольшим отставанием, с прямой ссылкой на полный экран
- **Карта компетенций** (Отчёты → «Карта компетенций»): презентационный отчёт для руководства — полное соответствие сотрудника всей шкале (12 направлений, все уровни), с прогресс-барами, сводкой по сильным/слабым сторонам, целями роста. Форматы: HTML (для показа/печати), PDF (через диалог печати браузера), Markdown, JSON. Имя сотрудника сохраняется между сессиями
- Автобэкап по пятницам (проверяется при каждом запуске)

### Данные шкалы компетенций

`scripts/domain/data/competency-scale.js` — полный перенос PDF-документа в структурированный JSON, без сокращений. В документе представлено только 3 уровня (Специалист / Старший специалист / Ведущий специалист) — младший и главный специалист сознательно не включены, так как для них нет критериев в исходнике.
